Auto Tab Groups

Click the toolbar icon or press ⌥⇧G to sort a window's ungrouped tabs; ones that fit nowhere move to the end. Tabs already in a group are never moved. Nothing changes until you ask, unless you turn on automatic placement below.

Anthropic API key

Create a key just for this extension, ideally in a workspace with a spend limit. It's stored in this Chrome profile only.

Model

Automatic

Off by default. When on, each new tab joins a group once it has loaded and you've switched away from it.

Your rules

Never send these sites

Sent to Anthropic: each tab's title and its address without the part after ? or #. Never sent: these sites (and their subdomains), pinned tabs, incognito tabs, and browser pages like chrome://.
